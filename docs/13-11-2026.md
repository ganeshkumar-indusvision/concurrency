1. Understand how to write threading and thread creation in python.
2. Created worker split for the thread.
3. Identfied why GIL act as blocker for threading.
4. With GIL Builds (python version < 3.14.3) all thread created under main thread was acting as async single threaded (illusional parallelism).
5. With GIL disabled (python version >= 3.14.3 and from 3.14t) all thread created under main thread  was acting as async multi threaded (True Parallelism).
6. Before GIL disabled only way to get True parallelism was with created multiprocess.
7. While testing multiprocessing found issue with `fork` error in 3.14.3 version. After doing RCA found that old python was just doing `fork` on creating of child process. New version is creating `forckserver` which is much similar to windows spwn (where it creates new python interpreter import main script causing infinite spawn creation) .
8. Lesson from this whenver we run script all the things should be inside `if __name__ == "__main__"`if condition to avoid running those things on importing this file.
